# قائمة إلزامية قبل الإطلاق الرسمي

هذه المرحلة للتجربة المحلية فقط. لا تطلقها إنتاجياً قبل إتمام البنود التالية والتحقق منها:

- [ ] تعطيل/إزالة Developer Test Mode وأوامره وcallback IDs، واختبار منع أي حساب غير مصرح له.
- [ ] إزالة Mock Services من تكوين الإنتاج وربط خدمات فعلية مختبرة ومصرح بها.
- [ ] حذف `mock_data/` التجريبي من بيئة الإنتاج وفحص أي نسخ أو fixtures غير مقصودة، وعدم نقلها إلى PostgreSQL باعتبارها سجلات عملاء.
- [ ] فصل بيئات staging وproduction وبياناتهما من البداية؛ عدم حذف بيانات تشغيلية حقيقية أثناء تغيير البيئة.
- [ ] تدوير أي أسرار تعرضت في الاختبار، وفحص Git والسجلات والـartifacts للتأكد من غياب token وكلمات المرور والمعرّفات الحساسة.
- [ ] إثبات فصل السجل المالي طويل الأمد عن البيانات التشغيلية قصيرة الاحتفاظ باختبارات حذف واستعادة، مع مراجعة الالتزامات القانونية للمالية.
- [ ] اعتماد سياسة نافذة الحصة عند تمديد نفس نوع الاشتراك، واختبار حالات انتهاء الاشتراك والطابور وتجدد الحصة والجدولة والتجميد والاستئناف.
- [ ] اختبار كل واجهات العربية والإنجليزية وcallback IDs القديمة، وتطبيق الصلاحيات في الخدمات لا في الأزرار فقط.
- [ ] الحصول على الأذونات اللازمة لأي تكامل طرف ثالث، واستخدام Sandbox أو بيئة مرخصة، وعدم عرض المحاكاة بوصفها نجاح شبكة.
- [ ] مراجعة حماية البروكسي وSSRF والتشفير وحدود زمن/حجم الطلبات وإدارة الأسرار والسجلات المنقّحة.
- [ ] إعداد ومراجعة النسخ الاحتياطية والاسترجاع، ثم اختبارات staging وproduction التشغيلية والأمنية قبل أي نشر VPS.
